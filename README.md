# Customer Shopping Behavior Analysis

An end-to-end data analytics project analyzing retail customer shopping behavior using **Python, SQL, and Power BI**.

## Project Overview

This project demonstrates a complete data analytics workflow, from data preparation and exploratory analysis to SQL-based business analysis and interactive dashboard creation.

The project focuses on understanding customer segments, purchasing behavior, loyalty patterns, and factors influencing customer purchases.

## Tools & Technologies

* **Python**
* **Pandas**
* **NumPy**
* **Matplotlib**
* **Seaborn**
* **MySQL**
* **Power BI**
* **DAX**

## Project Workflow

### 1. Data Preparation & EDA — Python

The raw customer shopping dataset was loaded and analyzed using Python.

Key steps include:

* Data import and exploration
* Data cleaning
* Handling missing values
* Data transformation
* Exploratory data analysis
* Identifying customer and purchasing patterns

### 2. Business Analysis — SQL

The cleaned data was loaded into a SQL database and analyzed using SQL queries.

The analysis focuses on business questions related to:

* Customer segmentation
* Purchase behavior
* Customer loyalty
* Product categories
* Purchase drivers
* Customer trends

### 3. Interactive Dashboard — Power BI

An interactive Power BI dashboard was created to present the analysis visually.

The dashboard helps stakeholders explore:

* Customer behavior
* Purchase patterns
* Customer segments
* Product trends
* Key performance indicators
